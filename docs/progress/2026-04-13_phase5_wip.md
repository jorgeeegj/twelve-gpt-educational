## Architecture decisions made

- **`is_big6` over rank≤6** — the Big Six is defined by club identity in English football, not final standings. 2024-25 saw Man United (15th) and Spurs (17th) still be Big Six. Using rank≤6 would include Newcastle and Aston Villa instead.
- **Two-step metric_derived_bucket** — rather than a hardcoded detector (v1 approach), the agent calls `rank_teams` first then `get_stat_vs_opponent_group`. This generalizes to any metric-derived bucket without code changes.
- **Benchmark as ground truth** — when DB and benchmark disagree, verify against DB. Several benchmark entries were written for the legacy rank≤6 definition and needed updating.
