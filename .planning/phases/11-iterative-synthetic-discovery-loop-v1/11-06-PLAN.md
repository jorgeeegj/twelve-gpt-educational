```python
from __future__ import annotations
from pathlib import Path
from typing import Optional

from evals.discovery.failure_backlog import (
    DEFAULT_BACKLOG_PATH,
    load_backlog,
    save_backlog,
)

PROJECT_ROOT = Path(__file__).resolve().parents[2]  # repo root
DOCS_REVIEW = PROJECT_ROOT / "docs" / "review"
FIXTURE_FIXES = Path(__file__).parent / "fixture_fixes"
REGRESSIONS_FILE = PROJECT_ROOT / "tests" / "test_synthetic_regressions.py"
ELIGIBILITY_THRESHOLD = 2  # 11-SPEC.md §8


class PromotionError(RuntimeError):
    """Raised when an entry is not eligible for promotion or the action is unknown."""


def promote(backlog_entry_id: str, backlog_path: Path = DEFAULT_BACKLOG_PATH) -> Optional[Path]:
    """Emit the proposal artefact for the entry's recommended_action.

    Pre-conditions:
      - The entry exists in the backlog at backlog_path.
      - entry['seen_count'] >= ELIGIBILITY_THRESHOLD.
      - entry['recommended_action'] is one of the 7 enum values.

    Effects:
      - Emits the artefact path described in 11-SPEC.md §8 (or returns None for
        non_actionable / deferred).
      - Updates the backlog entry: status='promoted', promoted_to=<artefact path or None>.
      - Saves the backlog.

    Returns the artefact Path, or None for status-only updates.

    Raises PromotionError if seen_count < threshold or recommended_action is unknown/null.
    """


def _emit_regression_test_stub(entry: dict) -> Path:
    """Append a commented-xfail stub to tests/test_synthetic_regressions.py.

    The stub is COMMENTED (every line starts with '#'). Humans uncomment after
    the production fix lands. Returns REGRESSIONS_FILE.

    Stub contents (template):
      # @pytest.mark.xfail(reason="<failure_signature> surfaced in <run_id>; promoted by Phase 11 LOOP-06")
      # def test_regression_<failure_signature_snake_case>():
      #     '''<failure_signature>'''
      #     answer = _ask_agent("<sample question text>")
      #     assert ...  # TODO: assert the failing condition explicitly
    """


def _emit_followon_doc(entry: dict, kind: str) -> Path:
    """Write docs/review/<kind>_<signature>.md with the proposal template.

    kind in {'follow_on', 'context_gap', 'tool_proposal'} — chosen by the caller
    based on recommended_action.

    Creates DOCS_REVIEW/ if missing. Returns the file path.
    """


def _emit_fixture_diff(entry: dict) -> Path:
    """Write a unified-diff suggestion to evals/discovery/fixture_fixes/<signature>.diff.

    Body is a placeholder template; humans edit it. Returns the file path.
    """


def _update_backlog_entry(backlog: dict, entry_id: str, status: str, promoted_to: Optional[str]) -> dict:
    """In-place update; returns the modified backlog."""
```

### Hard rules (enforce in implementation)

- `promote.py` MUST NOT edit any file under `src/basic_stats/`. There is no code path that opens or writes such a file.
- `_emit_regression_test_stub` MUST emit ONLY commented lines (every appended line starts with `#`). The xfail decorator is commented; the def is commented; the assertion is commented. Tests verify this.
- `promote.py` MUST NOT make network calls (no `import openai`, no `requests`, no `urllib`).
- `promote.py` MUST NOT call `git`, open PRs, or invoke `subprocess` for VCS operations.
- The eligibility check is `seen_count >= 2`. A single-occurrence entry raises `PromotionError`.

<action>
Create `tests/test_promote.py`. All tests use `tmp_path` for backlog isolation. Where the implementation needs absolute paths (`docs/review`, `tests/test_synthetic_regressions.py`, `evals/discovery/fixture_fixes`), monkeypatch `evals.discovery.promote.DOCS_REVIEW`, `REGRESSIONS_FILE`, and `FIXTURE_FIXES` to point inside `tmp_path` so the live repo files are never touched by the test suite.

Required tests:

1. `test_promote_raises_when_seen_count_below_threshold` — entry with `seen_count=1` → `PromotionError`.
2. `test_promote_raises_when_recommended_action_null` — entry with `recommended_action=None` and `seen_count=3` → `PromotionError`.
3. `test_promote_regression_test_needed_emits_commented_stub` — promotion produces a file (the monkeypatched regressions file) where every newly appended line starts with `#`. The signature appears in the stub.
4. `test_promote_agent_behavior_fix_writes_followon` — emits `docs/review/follow_on_<signature>.md`. File path is returned. Backlog entry's `promoted_to` is set to that path string.
5. `test_promote_context_missing_writes_context_gap` — emits `docs/review/context_gap_<signature>.md`.
6. `test_promote_helper_tool_writes_tool_proposal` — emits `docs/review/tool_proposal_<signature>.md`.
7. `test_promote_fixture_issue_writes_diff` — emits `evals/discovery/fixture_fixes/<signature>.diff`.
8. `test_promote_non_actionable_returns_none_and_status_promoted` — returns `None`; backlog entry status updates to `"promoted"`; `promoted_to` is `None`.
9. `test_promote_deferred_returns_none_and_status_promoted` — same shape as #8.
10. `test_promote_does_not_touch_src_basic_stats` — assertion: after running promotion for several action types, no file under `src/basic_stats/` was opened for write. (Test approach: pre-snapshot mtime of `src/basic_stats/agent.py`; after promotion, mtime is unchanged.)
11. `test_promote_never_enables_xfail` — emit a regression-test stub, then read the regressions file and assert: `count(uncommented_xfail_lines) == count_before_promotion`. (No new active `@pytest.mark.xfail` decorator.)
12. `test_promote_does_not_call_network` — patch `socket.socket` and `urllib.request.urlopen` to raise on call; promotion still succeeds.

The test file MUST NOT import `BasicStatsAgent` or DuckDB.
</action>
